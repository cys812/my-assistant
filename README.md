# 나만의비서 — 1단계

폰 크롬에서 설치해 쓰는 개인 기억 보조 앱(PWA)입니다. 모든 기록은 폰 안에서 암호화되어 저장되며 앱 서버가 없습니다.

## 1단계에 들어 있는 기능

| 기능 | 내용 |
| --- | --- |
| 홈 화면 | 날씨, 오늘의 영단어, 오늘의 명언, 오늘 일정, 할 일, 주요 뉴스(국내 5·해외 5), 카테고리 버튼, 빠른 기록 |
| 기록 | 제목·내용·날짜·금액·태그·사진, 편집, 휴지통(30일 보관) |
| 자동 분류 | 사용자 규칙(단어·태그·입력 경로 → 카테고리, 우선순위) → 기본 단서(영수증·일정·할 일·책·건강) → 미분류 |
| 분류 관리 | 카테고리 추가·이름 변경·순서·삭제, 규칙 켜기/끄기, 규칙 기존 기록에 재적용 |
| 일괄 이동 | 조건(카테고리·글자·태그)으로 고르고 미리보기 후 이동, 10초 되돌리기. 카테고리 화면에서 직접 골라 이동도 가능 |
| 통합 검색 | 제목·내용·태그(이후 단계: 사진 속 글자·녹취록)에서 검색, 카테고리별 건수, 강조 표시 |
| 공유 받기 | 갤러리·캡처 화면에서 '공유 → 나만의비서'로 사진·글 저장 |
| 보안 | AES-256-GCM 암호화, 비밀번호(PBKDF2-SHA256 60만 회), 복구 코드, 5분 자동 잠금, 암호화 백업·복원 |
| 오프라인 | 한 번 연 뒤에는 인터넷 없이도 열림(날씨·뉴스 제외) |

다음 단계: 2단계 구글 캘린더·Tasks, OneNote(개인 계정, 실기기 시험 먼저) · 3단계 사진 속 글자 인식 · 4단계 음성 녹취·받아쓰기 · 5단계 건강·재무 화면, 지문 잠금.

## 설치 방법 (약 15분, 한 번만)

1. **GitHub 저장소 만들기**: github.com에서 새 저장소(예: `my-assistant`)를 만들고 이 폴더 전체를 올립니다. 공개(Public)로 두어도 기록은 폰에만 있어 노출되지 않습니다. 무료 계정에서 Pages를 쓰려면 공개 저장소여야 합니다.
2. **Pages 켜기**: 저장소 → Settings → Pages → Source를 `Deploy from a branch`, Branch를 `main` / `/docs`로 저장. 1~2분 뒤 `https://<아이디>.github.io/my-assistant/` 주소가 생깁니다.
3. **뉴스 자동 수집 켜기**: 저장소 → Actions 탭 → 워크플로 사용 허용 → '뉴스 수집' → `Run workflow`로 한 번 실행. 성공하면 `docs/news.json`이 생기고, 이후 매시간 갱신됩니다.
   - 실패하면 Actions 기록의 오류 줄을 알려주세요. 뉴스 주소는 `news-sources.json`에서 바꿀 수 있습니다.
4. **폰에 설치**: 폰 크롬으로 2번 주소를 열고 메뉴 → '홈 화면에 추가'(또는 '앱 설치').
5. **처음 실행**: 비밀번호를 정하면 **복구 코드**가 한 번 나옵니다. 반드시 종이에 적어 두세요.

## 꼭 알아 두실 점

- 비밀번호와 복구 코드를 모두 잃으면 데이터를 열 수 없습니다(서버가 없어 '비밀번호 찾기'가 없음).
- 크롬의 '사이트 데이터 삭제'나 앱 삭제 시 기록이 지워집니다. 설정 → 백업 파일 내보내기를 주기적으로 해 주세요.
- 공유 시트로 받은 사진은 앱을 잠금 해제할 때 암호화됩니다. 그 전까지 잠시 폰 안 임시 보관함에 평문으로 있습니다.
- 날씨: [Open-Meteo](https://open-meteo.com)(비상업 무료, API 키 불필요). 뉴스 기본 출처: 연합뉴스TV 최신기사 RSS, BBC World RSS.
- 명언은 출처가 분명한 속담·고전 위주로 넣었고, 출처가 불확실한 문구는 뺐습니다. `docs/data.js`에서 고칠 수 있습니다.

## 폴더 구조

```
docs/                 앱(이 폴더가 웹에 게시됨)
  index.html, style.css, app.js, vault.js(암호화), classify.js(분류·검색)
  data.js(명언·영단어), config.js(기본 위치 등), sw.js(오프라인·공유), manifest.webmanifest, icons/
scripts/fetch-news.mjs  RSS → docs/news.json
news-sources.json       뉴스 출처 설정
.github/workflows/news.yml  매시간 뉴스 수집
```
